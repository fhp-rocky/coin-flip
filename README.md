# 硬币实验室

手机优先的中文扔硬币小游戏。纯 HTML、CSS 与 JavaScript，无第三方运行时依赖、无构建步骤、无后台和数据库。

## 本机试玩

需要 Node.js 20 或更新版本。无需安装依赖，在项目目录执行：

```sh
npm start
```

电脑访问 <http://localhost:4173>。同一局域网的手机可使用启动日志中对应的局域网地址；电脑必须保持运行，网络和系统防火墙也需要允许连接。

默认监听本机所有网络接口的 4173 端口。只允许电脑自身访问时运行：

```sh
COIN_HOST=127.0.0.1 npm start
```

修改端口可使用 `COIN_PORT=4174 npm start`。终端中按 `Ctrl+C` 停止服务。

## 游戏规则

- 初始余额 100 枚虚拟金币；金额为整数，最少下注 1 枚，加减步长为 1。
- 首次进入先填写昵称并查看规则，点击“开始挑战”后进入游戏并启动 10 分钟倒计时。昵称仅保存在当前标签页。
- 正面概率为 60%，反面概率为 40%，各轮独立，使用浏览器的随机数接口生成结果。
- 猜中净赚下注金额；猜错扣除下注金额；下注不能超过余额。
- 时间耗尽、余额归零或主动结束时结算。截止前已接受的投掷正常结算。
- 10%、20%、50% 和全部下注按钮根据当前余额计算，四舍五入为整数，最少 1 枚。
- 结果页使用同一组硬币结果，对比始终押正面、每轮下注余额 10% 或 20% 的策略。对比策略同样取整、最低 1 枚，破产后停止。

## 功能与数据

- 独立的昵称与规则开始页；游戏页、结算页和导出记录显示玩家昵称。
- “结束本局”为独立醒目的按钮，点击后确认结算。
- 结算页可“保存结果”为 1200×1960 的 PNG 图片，包含昵称、最终余额、统计与策略对比，不包含逐笔明细；提供图片预览，手机可长按保存。原有逐笔 CSV 导出保留。
- 内嵌矢量金属硬币，具有齿纹、浮雕字和翻转动画；系统要求减少动态效果时自动简化动画。
- 余额曲线、逐轮记录、结果统计、策略对比，以及带中文表头的 CSV 导出。昵称在页面上按纯文本显示；CSV 会转义昵称以避免公式注入。
- `sessionStorage` 保存当前标签页的对局，刷新可恢复；关闭标签页后不保证保留。后台停留或刷新不会重置计时。
- 不同浏览器和设备独立游戏，不需要登录。没有全球排行榜、跨设备存档或实时联机同步。
- 每次投掷先结算并保存，之后播放动画，动画期间禁止重复下注。
- 静态服务器只提供六个游戏文件，不提供内部说明、测试和服务器脚本。

20–30 人同时玩只会产生页面及静态资源的加载请求；投掷、计时、记录和图表都在各自浏览器本地计算，不持续请求服务器。客户端游戏不提供防作弊保证，虚拟金币无实际价值。

## 验证

```sh
npm test
```

规则测试覆盖初始金额、10 分钟时限、下注边界、破产、随机映射、策略对比、进度恢复和玩家状态隔离。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 中文页面及弹窗 |
| `styles.css` | 响应式布局、硬币样式和动画 |
| `app.js` | 页面交互、进度保存、图表和导出 |
| `engine.js` | 独立的游戏规则和统计逻辑 |
| `result-image.js` | 原生 Canvas 统计结果图片 |
| `assets/icon.svg` | 本地矢量图标 |
| `server.mjs` | 零依赖的本机静态服务器 |
| `tests/engine.test.mjs` | 游戏规则自动测试 |

## GitHub Pages 发布

仓库包含自动发布流程。首次启用时，在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。

启用后推送到 `main` 分支，或在 **Actions → 发布硬币实验室 → Run workflow** 手动执行。流程会先检查脚本语法、运行规则测试，再整理并发布网页文件。

网页本身无需编译。只发布 `index.html`、`styles.css`、`app.js`、`engine.js`、`result-image.js` 和 `assets/icon.svg`，外加空的 `.nojekyll` 标记；相对资源路径支持 GitHub Pages 的仓库子路径。远端无需运行 `server.mjs`，访问者也无需安装 Node.js。

玩法参考 [Elm Wealth Coin Flip](https://elmwealth.com/coin-flip/)，界面与代码独立制作，与 Elm Wealth 无关联。
