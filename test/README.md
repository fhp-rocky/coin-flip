# 硬币实验室测试版

测试地址：<https://fhp-rocky.github.io/coin-flip/test/>。

用户已于 2026-11-24 确认将本版同步到正式入口。本目录继续作为独立测试版保留；正式版使用仓库根目录文件。发布流程分别复制两套页面，测试脚本和文档不包含在网页产物里。

本版改动：

- 开始页用滑条选择 5–10 分钟，每步 1 分钟，默认 5 分钟。
- 游戏主界面移除正反面概率文字；随机规则保持原样，开始页和玩法说明仍可查看规则。
- 新开一局默认下注 1 枚；下注比例快捷按钮改为从 1 到当前余额的滑条，保留输入框和加减 1 按钮。
- 每次投掷显示全屏硬币特效，翻转、浮动光晕及进度条持续 3.5 秒；原生模态层屏蔽背景点击，Escape 无法提前退出，同时在逻辑层阻止重复下注。减少动态效果模式仍保留相同等待时间；刷新页面会继续等待剩余时间，不重新抽样或接受新下注。
- 动画结束后，在同一全屏页显示实际硬币结果、本次盈亏和余额。猜中使用绿色光芒与粒子效果，猜错使用柔和红色与轻微晃动。点击“继续挑战”返回游戏；本局已结束时点击“查看本局结果”进入汇总。结果停留期间倒计时继续，刷新仍保留本次结果。
- 时间到、破产与手动结束继续正常结算；结果图片显示本局选择的时长，CSV 逐笔导出保持原样。
- 测试版使用独立的 sessionStorage 键，不读取或覆盖正式版进度。

验证：`node --test test/tests/*.test.mjs`（从仓库根目录运行）。包含规则测试与模拟 DOM/时钟的控制器测试；不等同于真实手机浏览器测试。

后续未确认的改动仍先放在此测试目录；正式版使用“限时挑战”标识并沿用正式版进度键。
